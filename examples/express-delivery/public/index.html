Capture → Replay → Fix → Verify

  1. Click Calculate delivery fee. Initially it returns 500. TimeMachine captures the distance and the pricing service response.
  2. Open TimeMachine, select the latest delivery-api occurrence for your selected API occurrence and click Replay failure. The captured build should return 500 again.
  3. Fix this line in examples/express-delivery/src/app.js: 
    const RATE_FIELD = 'rate';
    Change it to: 
    const RATE_FIELD = 'ratePerKm';
    For the PostgreSQL flow, edit examples/express-delivery/src/database-app.js instead: 
    const DATABASE_RATE_FIELD = 'rate_per_km';
  4. Stop pnpm demo with Ctrl+C, then run pnpm demo again. It rebuilds and registers the updated app automatically. Reload this page.
  5. Open the same original incident and choose Verify application fix. It should return 200 and verify the correct fee using the saved distance and rate.
